## 浏览器固定页签布局

浏览器插件使用可展开、收窄的二级侧栏，只展示用户添加的固定页签；一级导航不再逐个列出这些网页。不区分常用和普通标签页，不提供临时标签列表、收藏区或新建标签页流程。没有固定页签时展示添加入口，不创建临时浏览器实例。其他插件的网页仍保留各自一级入口。详细交互见[界面设计](home-and-identity.md)。

本次调整保留已有稳定 ID、代理及浏览数据目录，网页按需加载，切换或排序不重建实例。网站请求的新窗口仍由既有受控原生弹窗处理，不自动新增固定页签。

## 目录与职责

```text
plugins/builtin/browser/         内置浏览器声明与 Vue 界面
src/                            宿主外壳、能力展示入口与本地调用
src-tauri/src/                   原生网页容器、调用守卫及 Windows 适配
src-tauri/crates/oriel-core/     平台无关的声明、配置和校验
```

内置插件随应用打包；宿主按入口类型及展示模式选择通用渲染器，不按插件 ID 或网址修改路由。外部插件交付文件夹可放入 `workspace.json` 同级的 `plugins/`，默认扫描其直接子目录中的 `plugin.json`。工作台设置显示默认位置，并允许配置额外读取目录 `pluginRoots`；旧的单插件目录 `pluginDirectories` 继续有效。源码目录与交付位置分开，不依赖开发机嵌套仓库。

先处理显式目录，再处理默认根目录和额外根目录；同一实际路径只加载一次，根内子目录排序，重复 ID 保留先加载的插件并显示诊断。扫描不递归、不主动跟随发现的目录符号链接；无效声明、缺少文件或不可读目录不影响其他有效插件。读取目录用于放置可信交付物，自动发现不自动执行安装、更新或启动脚本；服务仅在显式打开或依赖请求时启动。刷新方式为应用启动、保存设置或点击“重新加载接入”，不监听文件系统实时变化。

兼容网页声明在启动、保存设置或点击“重新加载接入”时读取，无需构建宿主。内置浏览器 Vue 界面随宿主构建；版本 2 已支持[本地服务最小接入](local-services.md)的 stdio-v1 通信。任意插件前端资源装载和通用安装更新仍未实现；用户选择的本地前置程序通过[专门的执行接口](web-page-preparation.md)托管，外部网页不能发起执行。

2026-10-22 用户授权实现目录自动发现、插件内说明与工具应用布局；准确字段如下。保留原 WebView、代理、前置等待及权限边界，不增加独立桌面外壳。

## 插件声明

外部插件示例：

```json
{
  "schemaVersion": 1,
  "id": "example.tools",
  "name": "我的工具",
  "version": "0.1.0",
  "capabilities": ["web-page"],
  "entries": [
    {
      "id": "dashboard",
      "title": "工作面板",
      "kind": "web-page",
      "url": "http://127.0.0.1:8080",
      "proxy": { "mode": "inherit" }
    }
  ]
}
```

- 声明版本 1 仅支持 `web-page` 能力；版本 2 的服务页面与前置资源见[本地服务接入](local-services.md)。外部入口类型为 `web-page`；内置插件另提供 `browser` 入口，选择固定页签工作区，不再作为临时浏览页。
- 插件及入口 ID 以小写 ASCII 字母或数字开头，仅含小写字母、数字、点、下划线与连字符；完整 ID 不超过 128 字节，不以点结尾，不使用 Windows 保留文件名。入口运行身份为 `<插件 ID>.<入口 ID>`，不得重名；`user` 插件名及 `user.` 命名空间留给用户网页。这些约束避免 Windows 文件系统上的大小写或文件名冲突。
- 标题为 1–80 个字符，固定网页需要 HTTP／HTTPS 地址。宿主内部地址、其他协议及包含账号密码的 URL 不接受。
- 不支持的声明、重复身份或无效入口使该插件声明加载失败，已登记的其他入口保留，界面显示诊断。配置及声明文件最大为 2 MiB。
- 外部入口的默认配置来自声明；当前界面可编辑用户自行添加的网页，修改外部入口通过更新声明后重新加载。

## 展示、说明与本地配置

### 版本 2 的应用布局和说明

`entries[].presentation` 可为 `browser`（默认）或 `application`。应用布局不显示浏览器地址栏及通用前进后退按钮，提供窗口拖动、窗口控件、可选说明入口和应用操作菜单；仍使用相同原生网页能力。版本 1 不接受应用模式或文档扩展，自定义浏览器页签只接受浏览模式。

插件顶层可声明 `documentation: "USER_GUIDE.md"`，路径相对于插件交付目录，只接受目录内不超过 256 KiB 的 UTF-8 `.md`／`.txt` 普通文件，拒绝绝对路径、父目录穿越与越界符号链接。声明加载时校验，读取时再次校验；缺失或无效文档产生插件诊断。宿主仅渲染标题、段落、列表和代码块等文本，不执行 HTML、脚本或外部链接。无此字段的旧插件正常工作。

```json
{
  "schemaVersion": 2,
  "id": "example.application",
  "name": "工具示例",
  "version": "1",
  "capabilities": ["web-page"],
  "documentation": "USER_GUIDE.md",
  "entries": [{ "id": "main", "title": "工具示例", "kind": "web-page", "presentation": "application", "url": "http://127.0.0.1:8080" }]
}
```

本地主界面通过 `plugin_documentation({entryId})` 读取说明，外部页面无该宿主权限；说明打开不要求启动工具后台。独立工具可用自身页面展示同一份说明，Tether 将同一源文件编入独立 UI，并原样放入交付目录。

### 本地配置与身份

宿主配置位于 Tauri 应用配置目录下的 `workspace.json`：

```json
{
  "version": 4,
  "pluginDirectories": [],
  "pluginRoots": [],
  "webEntries": [],
  "defaultProxy": { "mode": "system" },
  "browserSidebar": { "collapsed": false, "width": 240 }
}
```

`webEntries` 保存用户添加的固定页签，包含稳定 `id`、`title`、`kind: "web-page"`、`url` 及 `proxy`；ID 由宿主生成，数组顺序即二级侧栏顺序。拖拽或上移／下移向宿主提交完整 ID 列表，宿主拒绝重复、未知或遗漏 ID，再原子保存，排序不调用网页重建。一级导航顺序和默认入口编辑尚未实现；启动打开首页，移除当前固定页签后显示剩余首项，没有剩余项则留在浏览器空状态。

`browserSidebar` 保存用户的收窄偏好及展开宽度，宽度限定 200–360px，默认 240px；图标模式固定 52px。窗口较窄造成的自动收窄不覆盖偏好。读取版本 1／2／3 时在内存中迁移为版本 4 并补齐默认偏好，首次成功保存才更新文件版本，不更改既有记录、代理和数据目录。插件声明版本 1 保持浏览语义，版本 2 支持应用展示、文档和本地服务扩展，独立于宿主配置版本。宿主版本 3 曾增加 `theme`（`light`／`dark`），主题迁移与传播见[统一主题](workspace-theme.md)。宿主版本 4 和插件声明版本 3 支持[每网页前置程序](web-page-preparation.md)，旧服务与规则引用继续兼容，新旧前置绑定在同一入口互斥。

写入前完成校验，先写同目录临时文件并同步，再替换配置；成功后才更新内存。配置损坏、版本不支持或校验失败时保留原文件，宿主与内置浏览器入口仍可打开，但阻止保存配置，无法读取的用户页签不展示；修复或移走原文件后重新加载。界面错误会提供配置文件位置。

原生数据位于应用本地数据目录的 `web-profiles/<完整入口 ID>/`。每个入口独立保存 Cookie、缓存、网站存储和原生密码；同一网站登记为不同入口时也彼此独立。修改名称不改变身份和数据目录；移除入口默认保留数据。密码清除与移除入口是不同操作，当前未提供浏览数据目录的自动清理。

网站图标由已打开入口的 WebView2 `FaviconChanged`／`GetFavicon` 获取，沿用该入口的浏览环境，不使用第三方图标服务或提前加载未访问网页。宿主在本地数据目录保存登记网址校验记录及 `{完整入口 ID}.png` 纯图像缓存；读取时检查来源、图像格式、尺寸及大小。工作区快照（`HostSnapshot`）不包含图标二进制，前端通过 `web_favicon({entryId})` 按需读取，返回 `{ entryId, registeredUrl, dataUrl } | null`。内存缓存及请求去重绑定 `(entryId, registeredUrl)`，组件同时监听身份与登记地址；接收命令结果和图标事件前核对当前登记资料。保存、重新加载或删除入口时清除变更项，代次检查拦截旧请求，包括新地址更新及较新图标事件；首次访问前、无图标或读取失败时显示名称首字。磁盘缓存继续按登记来源校验，不提前加载全部网页。

版本 2／3 的插件顶层可选声明 `icon: "terminal"`，从宿主已有内置图标中为该插件入口选择终端图标；宿主通过快照中的 `pluginIcon` 展示，不按入口模式、网址有无或插件 ID 推断。Script Studio 显式声明此字段；未声明或值为 null 时，继续使用网站 Favicon 与名称首字回退，不影响其他插件。图标在发现后即可显示，无需启动服务。当前仅接受 `terminal`，其他值、图片路径或 URL 使该插件声明校验失败；版本 1 不支持此字段。不增加本地配置版本，任意图片图标能力仍延后。

仅接受与登记网址同来源的顶层网页返回的图标，允许图标文件来自 CDN；跨来源登录跳转不覆盖固定页签图标。异步回调检查导航代次与实例身份，避免旧页面回调覆盖新状态。缓存与图标事件只向本地主界面提供数据，外部网页不获得新增宿主权限；宿主 CSP 仅为内嵌图标增加 `img-src data: asset: http://asset.localhost`。

## 浏览、密码与代理

浏览模式工具栏提供地址栏、上一页、下一页、刷新／停止和设置；应用模式提供说明与操作菜单。原生导航事件同步地址、标题、历史状态及错误，包括重定向与单页应用地址变化。没有协议的普通域名补 HTTPS，本机地址补 HTTP。地址栏只影响当前浏览，不改写网页登记的初始地址。

每个入口按需创建独立子 WebView；切换只隐藏，不销毁页面或重置登录。新窗口请求创建受控临时网页窗口，继承发起入口的代理和浏览数据。设置、网页编辑、前置程序与说明优先使用下述悬浮层；回退本地弹窗、页签操作菜单与拖动侧栏时隐藏网页，操作完成后恢复；窗口或侧栏大小变化时同步原生内容区域。右键或菜单键操作无需先选择目标页签，菜单关闭后恢复键盘焦点。

Windows 使用 WebView2 原生密码保存、更新提示及登录填充。Oriel 不另做账号列表，不读取 Edge／Chrome 密码库，不把密码传入 Vue、配置或日志。是否识别登录表单由引擎与网站决定。“清除此入口的密码”使用原生 PasswordAutosave 数据类型，等待完成后刷新页面，不清除 Cookie 或退出登录。参考 [WebView2 密码接口](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2settings4)、[浏览数据清除接口](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2profile2)。

默认代理可为 `system`、`direct` 或 `custom`；网页可继承默认，或使用 `direct`／`custom` 覆盖。自定义代理示例：

```json
{ "mode": "custom", "address": "socks5://127.0.0.1:1080" }
```

首版支持不带认证的 HTTP 和 SOCKS5 地址；不接受代理用户名、密码、路径、查询或片段。默认代理初始跟随系统。该设置作用于宿主网页能力，不改变操作系统代理，也不自动代理未来其他插件的任意网络请求。

代理或固定网址变化时重建受影响的网页实例；代理变化保留当前网址和原有数据目录，浏览历史随实例重建。关闭对应临时窗口并等待旧浏览器进程释放后再创建，超时显示重试提示，绝不改用直连作为失败回退。

## 宿主接口与权限

本地界面通过 `workspace_snapshot`、`workspace_reload`、`workspace_save_entry`、`workspace_delete_entry`、`workspace_settings` 管理网页与配置；通过 `web_show`、`web_navigate`、`web_action`、`web_clear_passwords` 调用网页能力。`web-session` 事件只发送到本地主 WebView，提供网址、标题、加载、前进后退及错误状态，不传递凭证；`web-favicon` 事件向同一本地主界面更新网站图标，前端通过 `web_favicon` 按需读取已缓存图标。

`main-window` capability 使用精确 `webviews: ["main", "overlay"]`，不按整个窗口授权；每个新增命令另验证 main／overlay WebView 身份及本地来源，打开悬浮层仅允许 main 发起。外部网页及临时窗口没有宿主权限，关闭原生 WebMessage 与 HostObjects 接口。宿主本身继续禁止 iframe，网页通过独立原生视图显示。具体权限模型不等于操作系统沙箱。

## 悬浮层与关闭语义

Windows 设置、添加网页、编辑网页（含移除确认）、前置程序和插件说明五类宿主弹窗使用透明独立 `overlay` 窗口，覆盖首页、浏览器及插件布局入口。通过锁定 Tauri 2.12.4 的 `owner` 接口归属 `main`，不增加任务栏入口；移动、缩放、最大化及 DPI 变化按主窗口客户区物理坐标同步。普通关闭隐藏复用，主窗口退出销毁；创建失败保留主窗口。应用操作菜单、页签菜单、密码弹窗及插件业务弹窗保持现状，不迁移。

请求仍只包含 camelCase 的 `requestId`、`mode`、`entryId`、`confirmRemove`，不传任意 JSON 或网页副本。`overlay_status` 返回原生就绪、会话故障、请求阶段、耗时及失败原因；main 提交后，overlay 通过 `overlay_pending` 获取请求，读取最新快照查找入口并挂载 dialog，经 Vue `nextTick` 后按编号调用 `overlay_presented`。隐藏窗口不等待动画帧。主窗口轮询命令状态确认已显示；事件及原生脚本唤醒只加速读取，不携带可靠状态，也不决定首次打开是否成功。

请求串行，编号单调递增；取消会使已提交及尚未到达的同号请求失效。读取完成后、挂载前和原生显示前检查请求身份、阶段与截止时间。窗口操作和状态转换在原生主线程串行执行，状态锁不跨窗口调用或异步等待持有；超时、取消后的迟到读取、挂载及确认均不能重新显示窗口。记录创建、就绪、接收、挂载、显示和失败阶段的耗时；诊断包含请求号及模式。

初始化、挂载、窗口呈现或 IPC 基础设施错误立即上报，5 秒仅是无响应的最终上限。故障后本次 Oriel 会话直接使用本地弹窗，重启后重试。入口不存在、不可编辑或说明读取失败属于业务错误，向原入口显示具体原因，保留悬浮层后续可用性，不自动改为新建入口。新命令继续校验本地来源及 main／overlay 身份，只有 main 可提交，只有 overlay 可报告就绪、读取待处理请求或确认挂载，不扩大外部网页权限。

原生窗口和 WebView 背景显式透明，使用既有 Tauri Acrylic 接口，不使用 CSS 跨窗口模糊。每次显示前重读系统透明效果、高对比度、省电及系统版本条件；禁用或不支持时清除材质，保留普通半透明遮罩。Windows 11 22H2+ 另读取 DWM 属性检查材质设置；锁定版本在旧 Windows 上不返回底层材质调用结果，仍需目标平台视觉验收。系统也可能限制 Acrylic，见[微软说明](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)。材质降级不触发本地弹窗回退，也不隐藏底层网页。中央 dialog 使用现有不透明 surface，只保留一层轻量暗色遮罩；不启用点击穿透。

五类弹窗及本地回退共用外侧指针处理：同一主指针的按下、抬起均在最上层 dialog 边界外，才派发可取消的 `cancel`。内部点击、内部按下后拖出、外部按下后拖入、不同指针或已取消的手势均不关闭。外侧点击、Escape、关闭按钮及原生关闭统一使用原有取消路径；保存期间忽略关闭。设置中的前置程序关闭后返回设置，保留草稿并恢复面板入口焦点。关闭悬浮层后主窗口通过命令状态确认并恢复触发元素焦点，通知丢失时同样生效。

正常悬浮流程保留底层原生网页控制器、页面实例及后台生命周期。其他平台或基础设施失败回退沿用本地隐藏／恢复行为。主题仅定向发送给 main 和 overlay，打开时只读校准有效主题；保存后定向通知 main 重读快照，不广播工作区副本。

## 声明式插件 UI 插槽

版本 2／3 的插件顶层可选 `slots` 数组；版本 1 不接受扩展。省略字段时不新增 UI，保留原插件行为，不增加配置版本。每项支持：

| 字段 | 当前支持 |
| --- | --- |
| `target` | `sidebar:badge` 或 `header:action` |
| `id` / `title` | 可选身份与提示文字；ID 非空且不超过 64 字节、插件内唯一，标题不超过 128 字节 |
| `entryId` | 可选插件内短 ID 或完整入口 ID；省略映射至所有入口，指定时必须存在 |
| `badgeType` | 侧栏可选 `dot`、`status`、`count`；当前为静态声明标记，不提供动态状态／计数协议 |
| `action` | 标题栏必填，仅支持 `reload`／`refresh`、`settings`、`preparations`；侧栏不接受动作 |
| `icon` | 可选 `refresh`／`reload`、`settings`、`terminal`、`play`、`pause`、`panel`、`more`、`home`；省略按动作使用默认图标 |

浏览器布局和工具应用布局共用动作组件，统一图标、可访问名称、禁用状态及动作分发。刷新要求原生浏览可用、存在页面地址且当前不忙；设置和前置程序在不忙时可用，前置程序关联当前网页。不增加插件自定义执行接口；未知动作、非法图标、无效关联或重复插槽 ID 产生声明诊断，拒绝该声明且保留其他有效插件。
