# Oriel 首页与界面设计

- 更新日期：2026-10-21。
- 范围：应用外壳、单侧边栏、默认首页及内置浏览器的界面衔接。
- 关联：[当前设计基线](current-design.md)、[设计决策记录](workspace-and-plugins.md)。

## 已确认的 UI 原则

- **保持 UI 简洁，避免过多文字。** 围绕页面实际任务保留必要的标题、标签和说明，文字数量按需要取舍，避免用标语、介绍性文案和重复提示填充界面。
- **支持浅色、深色两套主题。**

简洁原则适用于 Oriel 的整体界面设计，不限定为某一页的固定内容清单。

## 当前首页

当前采用单条窄侧边栏和默认首页，主区域展示 Oriel 名称与轻微动效，通过留白形成视觉重点。当前首页的具体呈现是简洁原则的一次应用，后续页面按自身任务组织必要内容。

## 视觉方向

保留浅灰、通透、低对比的整体外观，柔光使用薄荷绿、蜜桃色与雾蓝，深色主题使用深墨色背景。应用图标采用用户提供的新黑白连写设计。

图形、色值、排版与动效可随界面需求继续调整，保持简洁和主题协调。

## 当前范围

当前增加浏览器及自定义网页入口，保留原有首页。网页页采用与无边框窗口控件一体化融合的紧凑工具栏（44px）和原生内容区域，消除冗余空白栏堆叠；Windows 原生恢复无边框窗口边缘拖拽缩放能力，并调整默认窗口尺寸至更舒展视口。代理、网页编辑及密码清除放在操作弹窗中，弹窗打开时隐藏原生网页视图。继续使用现有双主题、字体与图标体系，侧栏长列表独立滚动，小窗口工具栏自适应换行。

网页入口按登记顺序展示，以名称首字符及可访问名称区分；原生网页自身的主题和内容仍由网站决定。具体行为和边界见[网页接入初版](web-page-plugins.md)。
