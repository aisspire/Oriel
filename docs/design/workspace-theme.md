# 工作台统一主题

2026-10-24：本次只保留统一主题。新增网页前置脚本方案已撤回，原服务接入保持当前提交基线；不以主题工作引入新的生命周期或业务提供方设计。

## 配置与行为

- 工作台只有浅色、深色两种有效主题，不增加“跟随系统”选项。
- 桌面主题以 `workspace.json.theme` 为权威，取值 `light`／`dark`。配置版本 1／2 读取时在内存中迁移为版本 3，成功保存后才写回；版本 3 本轮仅用于主题，不更改插件声明版本或旧服务、前置引用。
- 首次接受原 localStorage 主题偏好；无记录使用浅色。持久化成功后删除旧偏好，失败时保留会话切换并显示诊断。独立前端预览继续保存本地界面偏好。
- Windows 主窗口创建时设置原生主题。每个 WebView2 Profile 在网页及弹窗首次导航前设置明确颜色偏好；异步初始化读取最新有效主题。已有和隐藏实例随切换更新，不刷新页面或重启后台。
- 网页的 CSS `prefers-color-scheme` 与 `matchMedia()` 可响应原生颜色偏好。网站固定配色继续由网站决定；任意原生程序直接查询 Windows 主题仍需工具适配。

## 验证边界

核心测试检查主题持久化、旧配置迁移及旧网页前置引用保留；前端执行类型检查和生产构建。Windows 主题、隐藏页、弹窗、快速切换和首次加载仍需目标环境实测，不能沿用历史结果宣称本轮通过。
