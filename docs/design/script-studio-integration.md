# Script Studio 独立插件接入

- 创建日期：2026-10-26；更新日期：2026-10-27。
- 范围：Oriel 接入与生命周期边界；脚本业务设计、配置、源码和交付由独立工具仓库维护。
- 相关契约：[本地服务](local-services.md)、[网页接入](web-page-plugins.md)、[当前基线](current-design.md)。

## 已确认要求

Script Studio 是 Windows 本地脚本管理工具，保留独立运行方式。开发目录为工作区内 `plugins/external/script-studio/`，使用独立 Git 仓库；父仓库忽略该目录，不注册子模块，不把源码目录作为正式运行路径。名称及插件 ID 暂沿用原型中的 Script Studio 与 `script-studio`。

工具管理本地脚本登记、分组、收藏、运行配置、实时输出与历史。不同脚本可并发，同一脚本最多一个运行实例。页面只提供非交互运行输出；WSL 脚本通过用户编写的 Windows 包装脚本调用，不增加宿主 WSL 环境管理或交互终端能力。

## 接入方式

完整目录包包含 Windows 可执行文件、独立网页资源、版本 2 plugin.json、前台 oriel.ps1 及 USER_GUIDE.md。用户将交付目录放入默认插件读取目录，或配置额外读取目录后重新加载接入。

- 插件显式声明 `icon: "terminal"` 作为自身侧栏图标；其他未声明的插件不受影响。
- 声明能力为 `web-page` 和 `local-service-v1`；入口使用 `service: "script-studio"`、`presentation: "application"` 及直连代理。
- 宿主沿用已有 stdio-v1 首行就绪、实例身份、status 往返核验及受认证 shutdown，不增加协议版本或插件专用路由。
- 读取声明及说明不启动后台；显式打开后启动并展示无地址栏应用页面。说明可在后台未启动时阅读。
- 工具网页只调用自己的回环后台；展示不授予宿主 Tauri 命令、文件或凭证权限。
- 原生网页的颜色偏好让工具响应宿主浅深主题，切换主题不刷新页面或重启任务。

宿主配置只保存接入目录及原有工作台设置。脚本路径、参数、解释器、分组和运行历史由 Script Studio 保存；Oriel 不建立第二份业务配置，也不把它作为网页前置程序的全局脚本表。

## 运行与退出归属

切换、隐藏、关闭页面和刷新界面保留后台任务。完整退出 Oriel 时，通过已核验实例请求清理该实例全部托管 Windows 进程树，然后结束包装入口；包括同一实例中从独立页面启动的任务。独立后台退出采用相同行为。

Script Studio 自身用实际进程句柄与 Windows Job Object 管理任务。主脚本结束而所属子进程仍存活时，运行保持活动；外部程序和历史 PID 不构成接管依据。异常退出后的历史标为中断，不自动重跑。

工具自身支持 Ctrl 点击在外部 PowerShell 终端执行已保存配置。外部任务由终端直接启动，不建立托管历史、不随 Oriel 或后台退出停止，也不通过安装目录内的 Script Studio 辅助程序等待。正常退出后台后可以替换插件文件而保留外部任务；用户脚本自身依赖的文件及旧版已经运行的辅助进程仍需另行安排释放占用。此功能与验证由独立工具维护，不增加宿主协议或自动更新器。

Windows 包装脚本可以前台调用 WSL，输出和退出码由工具记录；Windows Job 清理不保证终止 Linux 后台作业，Linux 侧清理由包装脚本负责。此限制不通过全局终止 WSL 规避。

同一数据目录只运行一个后台，已有实例经身份核验后复用；多 Oriel 会话共享仲裁留待后续需求。获取、安装、更新、脚本正文编辑及定时调度不随本次接入引入。
