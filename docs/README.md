# Oriel 文档导航

当前进入内置浏览器与网页接入初版阶段，设计基线更新至 2026-10-24。已新增最小插件声明、本地配置、网页侧栏入口及 Windows 原生浏览能力；并已新增 Windows stdio-v1 本地服务与前置资源最小接入；安装更新等其他生命周期能力继续延后。本文只索引纳入仓库的正式资料；长期设计方向不代表对应功能已实现。

2026-10-22 已实现插件内说明、默认及额外插件目录自动发现，以及通用工具应用布局。浏览器保留地址栏，工具应用通过声明选择无地址栏的布局，Tether 使用同一份随包说明供宿主与独立界面阅读。保留旧目录登记和版本 1 浏览语义；独立桌面应用并非当前必要条件，详见当前设计基线与网页接入规范。

浏览器已采用插件内可展开、收窄的二级侧栏，只管理用户添加的固定页签，不区分常用与普通标签页。侧栏宽度和页签顺序保存在本地配置，版本 1／2 配置在成功保存时迁移为包含主题及可选网页前置程序的版本 4；详见当前基线与界面设计。

独立 SSH 工具 Tether 已有独立实现，Oriel 已增加其所需的最小生命周期、前置资源等待与退出清理。其独立开发仓库位于工作区内 `plugins/external/tether/`，由父仓库忽略，业务设计与实现交接在该仓库维护；本仓库只记录宿主接入边界，不将其作为浏览器已交付能力。

2026-10-24 仅保留统一主题改动；此前全局脚本资源方案及移除旧提供方的改动已撤回；重新确认后新增按网页独立执行的最小前置程序，保留旧服务接入，见[网页前置程序](design/web-page-preparation.md)。原 stdio-v1 接入保持当前提交基线，主题配置与验证见[统一主题](design/workspace-theme.md)。
